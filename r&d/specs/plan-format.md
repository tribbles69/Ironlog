# The Ironlog plan format (`ironlog-plan` v1)

Written 2026-11-02 at Aaron's request: people may already follow a plan, so the
coach asks whether they want one built, and anyone can bring their own in. The
format is short and plain so **any AI can write it** — the lifter's own AI app
on their phone, or Claude inside Ironlog on their key (D8).

## Where it lives in the app

- **Coach → first question:** "Do you want me to build you a plan?" —
  *Build me a plan* · *I've got a plan — bring it in* · *No plan — I'll just
  log*. The coach menu also has *Bring in my own plan*.
- **Settings → Training program → Bring in a plan…**
- The sheet has three ways in:
  1. **Copy instructions for your AI** — puts the rules below plus the full
     exercise list on the clipboard, to paste into ChatGPT, Claude, Gemini or
     similar with the plan. The lifter pastes the reply back.
  2. **Write my plan** — Claude Haiku 5.5 on the lifter's key (`aiCall`,
     feature `plan`) with the same rules as its system prompt.
  3. **Paste or load a file** — plan JSON, or a full Ironlog program
     (`program.json` shape, with `workouts`).
- **Check the plan** shows every day, any exercise that isn't in the
  catalogue (added as the lifter's own), and anything guessed, then a start
  date and **Put it on my calendar**. Other programs with planned sessions get
  the usual Keep both / Replace question.

The instructions text is generated by `planFormatText()` in `index.html` (the
exercise list comes from the catalogue at that moment). **That function is the
source of truth; this file mirrors it** — change both together.

## The format

```json
{
  "format": "ironlog-plan", "version": 1,
  "name": "Short plan name",
  "weeks": 8,
  "weekdays": ["mon", "wed", "fri"],
  "days": [
    { "name": "Push", "exercises": [
      { "name": "Bench Press", "equipment": "barbell", "sets": 3, "reps": "6-10", "rir": 2 },
      { "name": "Triceps Pushdown", "equipment": "cable", "sets": 3, "reps": 12, "rir": 1, "notes": "superset with Lateral Raise" },
      { "name": "Back Squat", "sets": [ { "reps": 5, "rir": 4, "type": "warmup" }, { "reps": 3, "rir": 1, "type": "top" }, { "reps": 5, "rir": 2, "type": "backoff" } ] },
      { "name": "Plank", "sets": 3, "seconds": 45 },
      { "name": "Farmers Carry", "equipment": "farmers_handles", "sets": 3, "metres": 20, "kg": 60 }
    ] }
  ],
  "alternate": { "days": [ "...a B week, same number of days..." ] }
}
```

| Field | Rule |
|---|---|
| `weeks` | 1–52 weeks laid out on the calendar; default 8 |
| `weekdays` | One per day, in order (`mon` … `sun`). Missing or wrong → spread over the week (1 day Mon; 2 Mon/Thu; 3 Mon/Wed/Fri; 4 Mon/Tue/Thu/Fri; 5 Mon–Fri; 6 Mon–Sat) with a note |
| `days[].exercises[].name` | A catalogue name where one fits (resolved through the same names and aliases as every importer). Anything else becomes the lifter's own exercise, flagged on the check screen |
| `equipment` | An equipment id; common words are understood (`dumbbell`, `trap bar`, `smith machine`, `bands`, `SSB`…). Unknown → the usual version, with a note |
| `unilateral` | `true` for single-arm / single-leg |
| `sets` | A number (all sets alike) or a list of sets, each with any of `reps`, `rir`, `kg`, `type`, `seconds`, `metres` |
| `reps` | A number, or a range `"6-10"`: the sets start at the bottom and the range goes in the note, so the D5 double progression reads it |
| `rir` | Target reps in reserve, stored as the set's `t`. **Preferred to `kg`**: a plan with no `kg` anywhere installs as `loads: "rir"` (weights from history, autoreg-spec → Plans with no weights) |
| `kg` | A fixed load. Any `kg` in the plan makes it a weighted program; sets without one start blank |
| `type` | `warmup`, `working` (default), `top`, `backoff`, `amrap`, `drop` |
| `seconds` / `metres` | Holds (logged as isometric) / carries and sleds |
| `notes` | Shown with the exercise. Ironlog reads "superset with …", "tempo 3-1-1-0" and modifiers like "paused" |
| `alternate.days` | B week, same number of days as `days`: odd weeks use `days`, even weeks these |

Errors stop the import with a plain message (no JSON found, no days, a day
with no exercises, more than 7 days). Everything else is fixed up and listed.

## Why a separate format rather than `program.json`

`program.json` lists every session of every week (the 8-week shipped program
is 40 sessions), which is long for an AI to write and easy to get wrong. The
plan format is one week (plus an optional B week) and a week count; Ironlog
expands it. Full programs still import as they are.
